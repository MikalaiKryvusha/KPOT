# ЧАСТЬ 1. Пять вариантов дизайна

Все пять делают одно и то же и одинаково безопасны. Разница в том, **что человек видит в главный
момент** — когда решает, запускать сортировку или нет. Выберите один; можно смешать (я скажу, как).

---

## Вариант 1 — «Мастер»: один шаг на экране

Как установщик программы: четыре крупных шага, назад-вперёд, ничего лишнего на экране.

```
┌──────────────────────────────────────────────────────────────┐
│  KPOT — разбор фотоархива                      Шаг 2 из 4    │
│  ●─────────●─────────○─────────○                             │
│  Папка     Изучаю    План      Готово                        │
│                                                              │
│                                                              │
│        Изучаю вашу папку. Ничего пока не трогаю.             │
│                                                              │
│        ██████████████████░░░░░░░░░░   8 431 из 12 004        │
│        осталось примерно 4 минуты                            │
│                                                              │
│        Уже нашлось: фотографий 7 902 · видео 412             │
│                                                              │
│                                        [ Остановить ]        │
└──────────────────────────────────────────────────────────────┘
```

**Оптимизирован под:** человека, который боится что-то сломать. Невозможно нажать не то — на экране
почти всегда одна кнопка.
**Плюсы:** самый понятный для новичка; естественно ведёт через четыре гарантии безопасности; проще
всего писать простым языком, потому что на каждом шаге объясняется ровно одна вещь.
**Минусы:** вам, знающему свой архив, будет тесно — придётся кликать «Далее» там, где хотелось бы
видеть всё сразу. Плохо подходит для повторных запусков (доливки).
**Цена:** самый дешёвый в разработке. [AI]Оценка: 1 фаза[/AI].

## Вариант 2 — «Было → Станет»: две панели

Главный экран — сравнение: слева ваш хаос сейчас, справа будущая библиотека, между ними стрелки.
План перестаёт быть текстом и становится картинкой.

```
┌───────────── КАК СЕЙЧАС ─────────────┬──────────── КАК СТАНЕТ ────────────┐
│ 📁 Фото с телефона            431    │ 📁 2013                            │
│    IMG_20130704_101112.jpg ──────────┼─▶ 📁 Лето                    118   │
│    IMG_20130705_180032.jpg ──────────┼─▶      IMG_20130704_101112.jpg     │
│ 📁 Разное                    1 204   │ 📁 2014                            │
│ 📁 копии                        88 ──┼─▶ 📁 ПРОЧЕЕ / дубликаты       88   │
│ 📁 Новая папка (2)              12 ──┼─▶ 📁 НА_РАЗБОР  ⚠ нужно решение    │
└──────────────────────────────────────┴────────────────────────────────────┘
   812 перемещений · 4 спорных · 5 папок опустеет · 0 файлов потеряется
                      [ Показать сухой прогон ]  [ Выполнить ]
```

**Оптимизирован под:** доверие. Человек видит результат до того, как он случился, и узнаёт свои папки.
**Плюсы:** самый убедительный экран из пяти; сразу видно, что ничего не пропадает; отлично объясняет
слово «план».
**Минусы:** на 71 606 файлах обе панели огромны — нужна свёртка, поиск, «показать только изменения»;
это самый сложный экран из всех.
**Цена:** [AI]дороже варианта 1 примерно вдвое[/AI].

## Вариант 3 — «Документ»: одна длинная страница-отчёт

То, что KPOT печатает сейчас, но в браузере: разделы, оглавление сбоку, липкая шапка с итогом и
кнопкой. Можно листать, искать, распечатать и показать жене.

```
┌──────────────────────────────────────────────────────────────┐
│ План разбора: 812 перемещений, 4 спорных   [ Выполнить ]  ▲  │
├─────────────┬────────────────────────────────────────────────┤
│ Что куда    │  ЧТО КУДА ПЕРЕЕДЕТ                             │
│ Дубликаты   │  ── 2013 / Лето ──────────────────────────     │
│ Спорные (4) │    IMG_20130704_101112.jpg                     │
│ Опустеют(5) │        ← Фото с телефона/IMG_20130704_...      │
│ Останется   │        снято 4 июля 2013, 10:11 — по данным    │
│ Откат       │        самой фотографии                        │
└─────────────┴────────────────────────────────────────────────┘
```

**Оптимизирован под:** внимательное чтение. Это ревизия, а не панель управления.
**Плюсы:** ближе всего к уже готовому (текстовый отчёт существует и проверен); печатается; легко
делать язык человеческим — это текст, а не иконки.
**Минусы:** выглядит как документ, а не как программа; «обычный ПК юзер» может не понять, что от него
хотят, и просто пролистать вниз.
**Цена:** самый дешёвый после варианта 1.

## Вариант 4 — «Проводник с фотографиями»

Привычное окно файлового менеджера: слева дерево папок, справа сетка миниатюр. Переключатель вверху:
«сейчас / после сортировки» — дерево перерисовывается.

```
┌────────────────┬─────────────────────────────────────────────┐
│ ○ сейчас  ● после сортировки        [ Выполнить сортировку ] │
├────────────────┼─────────────────────────────────────────────┤
│ ▾ 2013         │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│   ▸ Весна  62  │  │ 🖼 │ │ 🖼 │ │ 🖼 │ │ 🖼 │ │ 🖼 │        │
│   ▾ Лето  118  │  └────┘ └────┘ └────┘ └────┘ └────┘        │
│     видео   9  │   4 июля  4 июля  5 июля  5 июля  7 июля    │
│ ▸ 2014         │                                             │
│ ▸ ПРОЧЕЕ   96  │  ⚠ у 4 фотографий дата спорная — показать   │
└────────────────┴─────────────────────────────────────────────┘
```

**Оптимизирован под:** узнавание. Это единственный вариант, где видно сами фотографии, а не их имена.
**Плюсы:** ощущается как фотоприложение; спорные случаи можно посмотреть глазами («это точно зима?»).
**Минусы:** миниатюры надо откуда-то взять — это декодирование десятков тысяч снимков, отдельная
подсистема и главный источник тормозов. Риск превратить простую задачу в фотогалерею.
**Цена:** самый дорогой из пяти. [AI]Оценка: 2–3 фазы, и половина из них — миниатюры[/AI].

## Вариант 5 — «Панель безопасности»

Главный экран — крупные карточки с итогами и четыре «светофора» ваших гарантий из `GOAL.md`. Каждая
карточка открывает подробности.

```
┌──────────────────────────────────────────────────────────────┐
│  D:\Фото — 12 004 файла                                      │
│                                                              │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐          │
│  │ Разложится   │ │ Спорных      │ │ Ждут вашего  │          │
│  │    11 892    │ │      4       │ │  решения: 5  │          │
│  │  по годам ▸  │ │  посмотреть ▸│ │   открыть ▸  │          │
│  └──────────────┘ └──────────────┘ └──────────────┘          │
│                                                              │
│  Прежде чем что-то сдвинется:                                │
│   ✅ карта готова   ✅ бэкап будет   ✅ сухой прогон  ✅ откат │
│                                                              │
│                                   [ Выполнить сортировку ]   │
└──────────────────────────────────────────────────────────────┘
```

**Оптимизирован под:** спокойствие. Главный экран отвечает на вопрос «а не потеряю ли я фотографии»
раньше, чем на вопрос «куда что поедет».
**Плюсы:** четыре обещания из `GOAL.md` становятся видимыми — это и есть главный смысл интерфейса;
хорошо масштабируется на 71 606 файлов, потому что показывает числа, а не списки.
**Минусы:** сам план спрятан на второй уровень; человек может нажать «Выполнить», не открыв его.
**Цена:** средняя.

## [AI]Что рекомендую[/AI]

**Вариант 1 как скелет + экран плана из варианта 2.** То есть: мастер ведёт человека по четырём
шагам (это защита от дурака в чистом виде), но на третьем шаге он видит не список, а картину
«было → станет». Вариант 5 при этом отдаёт одну свою деталь — строку из четырёх галочек-гарантий,
она стоит внизу на каждом шаге.

Почему не 4 (миниатюры): это отдельный продукт внутри продукта, и он не нужен, чтобы решить вашу
задачу. Предлагаю вернуться к нему после первой версии — вопрос Q5 ниже.

# ЧАСТЬ 2. Что нужно согласовать (10 вопросов)

Отвечать можно коротко: «Q1 — вариант 1+2, Q2 — А…». Где не ответите — возьму рекомендацию и скажу.

### 🔴 Блокирующие (без ответа начинать нельзя)

**Q1. Какой дизайн?** 1 / 2 / 3 / 4 / 5 / смесь. *Рекомендация: 1 + экран плана из 2.*

**Q2. Как программа попадает на чужой компьютер?**
 А) **Установщик .exe**: «Далее → Далее → Готово», ярлык появляется сам. Внутри — программа вместе с
   рантаймом, ничего доустанавливать не нужно (~50–80 МБ).
 Б) **Портативный ZIP**: распаковал, запустил ярлык изнутри папки. Без установки и без прав
   администратора, но человек сам решает, куда распаковать.
 В) **И то, и другое.**
 Г) Через терминал (`npm i -g kpot`) — только для технических людей.
 *Рекомендация: **В**, но проектируем под А — только он честно закрывает «обычных ПК юзеров».*

**Q3. Подпись программы (SmartScreen).** Windows на неподписанной программе показывает синее окно
«Windows защитила ваш компьютер». Это не вирус — просто у файла ещё нет репутации, но неопытный
человек читает это как «опасно».
 А) Пока **без подписи**, а в установщике и в README честно написать простыми словами, что он увидит
   и что нажать. Бесплатно.
 Б) **Купить сертификат** подписи — предупреждение исчезает. Это ежегодные деньги (порядок — сотни
   долларов в год) и возня с продлением.
 *Рекомендация: **А** сейчас, **Б** — когда появятся пользователи кроме нас.*

**Q4. Сколько трения перед кнопкой «Выполнить»?**
 А) **Одно осознанное подтверждение с числами**: «Перемещу 812 файлов. Бэкап сделан, откат одной
   кнопкой». [ Отмена ] [ Да, сортировать ]
 Б) **Ввести слово** «сортировать» руками — как в опасных операциях на сайтах.
 В) **Без подтверждения** — откат же есть.
 *Рекомендация: **А**. Б — это про необратимые действия, а у нас всё обратимо, и лишний страх только
 научит людей кликать не глядя (разведка §5.6).*

### 🟡 Важные, но у меня есть безопасный вариант по умолчанию

**Q5. Показывать ли сами фотографии (миниатюры)?**
 А) **В первой версии — нет.** Имена, даты, папки.
 Б) **Только для спорных** — там, где вы сами решаете «зима это или лето», картинка помогает.
 В) Полноценная сетка миниатюр везде.
 *Рекомендация: **Б** — это 20 файлов, а не 71 606, и именно там глаз нужен.*

**Q6. Что значит «закрыть окно»?**
 А) **Окно и есть программа**: закрыли вкладку — тихо остановилась. Нечему остаться висеть.
 Б) Продолжает работать в фоне, чтобы можно было вернуться.
 *Рекомендация: **А** — «я закрыл, а оно работает» это главная претензия к таким программам (§5.4).*

**Q7. Папки, по которым нужно ваше решение** (сейчас это текстовый файл `папки-на-согласование.txt`).
 А) **Перенести решение в интерфейс**: список папок, у каждой две кнопки «Разобрать» / «Оставить как
   есть». Файл остаётся как запасной путь.
 Б) Оставить только файл.
 *Рекомендация: **А**.*

**Q8. Язык интерфейса.** А) только русский. Б) русский + английский (репозиторий-то публичный).
 *Рекомендация: **А** в первой версии; английский — когда появится английский пользователь.*

**Q9. Лицо программы.** Ставим ли в окно логотип KPOT, и как называется само окно: «KPOT», «KPOT —
разбор фотоархива», или ваше название? Иконка ярлыка — тот же логотип?
 *Рекомендация: окно «KPOT — разбор фотоархива», логотип в шапке, иконка ярлыка из него же.*

**Q10. Доступ с других устройств.** А) **Только этот компьютер.** Б) Хочу иногда открывать с телефона
по домашней сети.
 *Рекомендация: **А**. Б превращает несколько теоретических рисков в настоящие и требует пароля;
 сделать можно, но это отдельное решение и отдельная работа.*
