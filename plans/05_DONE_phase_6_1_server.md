## 1. Задача в одном предложении

Поднять на этом компьютере маленький сервер, который умеет запускать четыре фазы KPOT через
`src/app/phases.mjs`, отдавать браузеру их результаты и живой ход работы, **не давать себя
использовать чужой веб-странице**, не поднимать себя вторым экземпляром и выключаться по явной
кнопке — потому что закрытие вкладки его не останавливает, так решил владелец.

## 2. Что решено владельцем и не обсуждается

| Решение | Его слова |
|---|---|
| Сервер и «морда» разделены; закрытие морды сервер не останавливает | «у приложения есть бекенд-сервер, и WEB UI "Морда". Закрытие Морды не влияет на сервер - он работает» |
| Только этот компьютер, никакого доступа по сети | Q10 = А |
| Два языка с переключателем, русский по умолчанию | Q8 = Б |
| Окно называется «Krinik Photo Organizer Tool (KPOT)» | Q9 |

Три обязательства, которые создаёт разделение, и все три — в этой фазе: явное **«Завершить
работу»** · повторный запуск ярлыка **находит работающий сервер**, а не поднимает второй ·
**сервер остаётся единственным писателем** (морда не пишет ничего).

## 3. Что делаем — по пунктам, каждый со своей причиной

| Пункт | Как | Почему именно так (чужая шишка) |
|---|---|---|
| Слушаем только себя | `server.listen(port, '127.0.0.1')` | — |
| **Токен** | выдаётся при старте, живёт в ссылке, которую открывает программа; без него любой запрос отклоняется | модель Jupyter. «Слушает только localhost» — не модель безопасности |
| **Белый список `Host`** | принимаем только `localhost` / `127.0.0.1` (с портом и без) | DNS rebinding: у Glances, инструмента ровно нашей формы, есть заведённая уязвимость именно из-за отсутствия этой проверки |
| **Порт с откатом** | пробуем свой, при занятости берём случайный свободный; человеку показываем НАСТОЯЩИЙ адрес | так делает Syncthing; ярлык не имеет права зашивать порт |
| **Браузер после `listening`** | открываем окно только по событию, никогда до | иначе первый же запуск встречает человека ошибкой соединения |
| **Один экземпляр** | при старте пишем файл состояния (порт, токен, pid); повторный запуск читает его, проверяет, что сервер жив и НАШ, и просто открывает морду на нём | без этого первое же двойное нажатие ярлыка даёт конфликт порта |
| **«Завершить работу»** | явная ручка выключения + запись состояния убирается | «я закрыл, а оно работает» — главная претензия к программам этого класса |
| **Живой ход работы** | `text/event-stream`, кормится существующим `src/core/progress.mjs` | одна строка на Node, без зависимостей; WebSocket потребовал бы библиотеки |

**Чего в этой фазе НЕТ:** мастера, пульта, вёрстки. Страница здесь — заглушка, доказывающая, что
сервер живой и защита работает. Лицо — это 6.2 и 6.3.

## 4. Границы, которые нельзя перейти

- **RULE 1.** Сервер ничего не пишет сам: любая запись — только через `src/app/phases.mjs` →
  `src/apply/`. Морда не пишет ничего вообще.
- **RULE 2.** `src/ui/` стоит НАД `src/app/` и не имеет права звать `src/apply/`, `src/plan/` и
  ниже напрямую. Это проверяется спекой, а не обещанием.
- **Ноль новых зависимостей.** `node:http`, `node:crypto`, `node:fs`. Ничего больше.

## 5. Критерий приёмки

Каждая проверка сначала ломается (EXP-0008), иначе её зелёный ничего не значит.

1. запрос без токена отклонён; с токеном — принят;
2. запрос с чужим `Host` отклонён, даже если токен верный;
3. занятый порт → сервер поднимается на другом, и адрес, который он сообщает, действительно рабочий;
4. второй запуск **не поднимает второй сервер**, а возвращает адрес уже работающего;
5. «Завершить работу» останавливает сервер и убирает файл состояния;
6. `src/ui/` не импортирует ничего ниже `src/app/`;
7. долгая работа переживает «закрытие вкладки» (обрыв соединения не отменяет прогон).

## 6. Решения, принятые без владельца

Все внутренние и дешёвые в отмене. Продуктовых развилок не возникло — а если бы возникла, она ушла
бы отдельным интервью, как вы и сказали 2026-07-29.

1. **Порт по умолчанию — 5768.** Число произвольное: высокое (не требует прав), необычное (обычно
   свободно). На телефонной клавиатуре набирается как «KPOT» — единственная причина предпочесть его
   любому другому свободному числу, и то лишь чтобы его было легче назвать в разговоре.
2. **Токен едет в ссылке** (`?token=…`), как у Jupyter, плюс принимается заголовком для последующих
   запросов. Иначе первое открытие окна потребовало бы от человека что-то вводить руками.
3. **Файл состояния — в системной временной папке.** Он не секрет и не настройка: живёт ровно
   столько, сколько работает программа, и нужен только чтобы второй запуск нашёл первый.
4. **Страница-заглушка.** Мастер — это 6.2, пульт — 6.3. Здесь страница лишь доказывает, что сервер
   жив и выключатель работает.
5. **Двуязычие ещё не заведено.** Словарь строк начинается с 6.2, где появляется первый настоящий
   текст интерфейса; заводить словарь ради трёх строк заглушки — работа впустую.

## 7. Итог фазы — измеренный

- **`npm test` 200 → 215.** Пятнадцать проверок на сервер, и **каждая защита проверена на сломанном
  коде**: убрать проверку `Host` — краснеет 1, убрать токен — 3, убрать откат порта — 1, поверить
  файлу состояния без проверки — 1, не закрывать потоки при выключении — 1, не забывать ушедшую
  вкладку — 1.
- **Живая проверка на этой машине:** `kpot ui` поднялся на 5768 и открыл браузер; **второй запуск
  вернул тот же адрес**, а не поднял второй сервер; «Завершить работу» оставила порт закрытым и
  удалила файл состояния.
- Пометки `[NOT-TESTED]` сняты только там, где наблюдение действительно было.

## 8. Два дефекта — в моих собственных проверках, не в сервере

Оба найдены проходом «сломай и посмотри, покраснеет ли», и оба относятся к классу «проверка зеленела
по неверной причине»:

1. **Спека про подмену `Host` использовала `fetch`,** а для `fetch` заголовок `Host` запрещён и молча
   выбрасывается. То есть проверка защиты от DNS rebinding **никогда не отправляла ту атаку, которую
   изображала**. Переписана на сырой `node:http`.
2. **Спека про занятый порт поднимала сервер ДО `try`.** При сломанном откате порта запуск падал, мой
   же занятый сокет оставался открытым, и прогон **зависал вместо того, чтобы покраснеть**. Защита,
   которая вешает прогон, — это защита, которую перестают запускать.
